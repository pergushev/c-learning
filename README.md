## 🧱 Ключевые структуры данных

```c
// contact.h
typedef struct {
    char name[100];
    char phone[20];
} Contact;

typedef struct {
    Contact *data;   // Динамический массив
    int size;        // Текущее количество контактов
    int capacity;    // Выделенная ёмкость
} PhoneBook;
```

## 💡 Советы по реализации

1. **Начните с `struct`** — опишите `Contact` и `PhoneBook` до написания функций.
2. **Реализуйте `realloc`** — удваивайте `capacity` при нехватке места.
3. **Загрузка при старте** — вызовите `load_from_file()` в самом начале `main()`.
4. **Сохранение при выходе** — вызовите `save_to_file()` перед `free()` и завершением.
5. **Поиск без регистра** — используйте `tolower()` из `<ctype.h>`.
6. **Цвета в терминале** — используйте ANSI-коды: `\033[1;32m` — зелёный, `\033[0m` — сброс.
